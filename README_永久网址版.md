# 永久网址方案：静态托管版（不会失效）

## 为什么之前那个链接会"没了"

| 方案 | 网址能开多久 | 原因 |
| --- | --- | --- |
| ❌ 我本机起的 Streamlit | 关机/关会话就没了 | 跑在你电脑上 |
| ❌ 内网穿透隧道 | 几分钟~几小时 | 临时隧道，断开即失效 |
| ✅ **WorkBuddy / CloudStudio 静态托管** | **长期有效** | 静态文件托管在云上，不依赖任何人的电脑开机 |

## 让链接"不失效"的检查清单

- [x] 纯静态文件（无后端进程、无数据库、无定时任务）
- [x] 无第三方 CDN 依赖（样式/脚本全部内联，不联网也能打开）
- [x] 无 API Key 也能完成完整演示（端侧引擎离线可用）
- [x] 不依赖任何人的电脑开机、不依赖隧道
- [ ] **每次改动内容后，必须在 WorkBuddy 里重新发布一次**（这是唯一的"续命"动作）
- [ ] 建议同时把 `e护校园_反诈研判_静态版.html` 单独备份一份到网盘/U盘

> 如果你希望**连"重新发布"都不用**、内容更新后网址自动生效，
> 那就换一个 Git 驱动的静态托管（Cloudflare Pages / Vercel / GitHub Pages）：
> 推一次代码，几分钟后全网自动更新，网址永久固定。需要的话我帮你把仓库初始化好。
